# 🎮 Alirn - Интернет-магазин цифровых товаров

Централизованный интернет-магазин цифровых товаров (ключи игр, подарочные карты) в стиле Steam на Django.

## 🚀 Быстрый старт

### Требования

- Python 3.10+
- Django 4.2 LTS
- Pillow (обработка изображений)

### Установка

1. **Клонируйте/распакуйте проект:**

```bash
cd r:\ucheba\Alirn
```

2. **Создайте виртуальное окружение (уже создано):**

```bash
python -m venv venv
venv\Scripts\activate
```

3. **Установите зависимости (уже установлены):**

```bash
pip install Django==4.2 Pillow
```

4. **Примените миграции (уже сделано):**

```bash
python manage.py migrate
```

5. **Загрузите тестовые данные:**

```bash
python seed_data.py
```

6. **Создайте суперпользователя (уже создан):**

```
Логин: admin
Пароль: admin
```

### Запуск сервера

```bash
python manage.py runserver
```

Сервер запустится на `http://localhost:8000`

## 🎨 Технические особенности

- **Фреймворк:** Django 4.2 LTS
- **БД:** SQLite (встроенная, не требует установки)
- **Фронтенд:** Django Templates + Bootstrap 5 + JavaScript
- **Аутентификация:** Встроенная система Django
- **Защита:** CSRF, XSS, SQL-injection
- **Обработка изображений:** Pillow
- **Платежи:** Эмуляция (без реальных платежей)

## 📝 Модели данных

### Game (Игра)

- Название, описание, разработчик, издатель
- Дата выхода, платформа, жанр, регион
- Цена, скидка в процентах
- Изображения, системные требования
- Счётчики просмотров и продаж

### GameKey (Ключ активации)

- Уникальный ключ
- Статус использования
- Связь с игрой

### Order (Заказ)

- Пользователь, список товаров
- Общая стоимость, статус
- Дата создания

### Review (Отзыв)

- Оценка (1-5 звёзд)
- Текстовый комментарий
- Дата создания и обновления

### UserProfile (Профиль пользователя)

- Баланс кошелька
- Аватар
- Список избранных игр
- Список купленных игр

### BalanceTopUp (Пополнение баланса)

- Сумма, статус успеха
- Дата операции

## 🔒 Безопасность

- Все пароли хешируются встроенным механизмом Django
- Защита от CSRF на всех POST-запросах
- Предотвращение XSS-атак через шаблонизацию Django
- Валидация данных как на клиенте, так и на сервере
- Транзакции БД для критических операций (покупка, пополнение)

## 📊 Примеры использования

### Регистрация пользователя

1. Перейдите на страницу регистрации
2. Заполните форму (имя пользователя, email, пароль)
3. Система автоматически создаст профиль и корзину

### Покупка игры

1. Найдите игру в каталоге или через поиск
2. Нажмите "Добавить в корзину"
3. Перейдите в корзину
4. Нажмите "Оформить заказ"
5. Система проверит баланс
6. После оплаты игра появится в вашей библиотеке

### Пополнение баланса

1. Перейдите в профиль → Баланс
2. Нажмите "Пополнить баланс"
3. Выберите сумму или введите собственную
4. Следуйте инструкциям платежа
5. Баланс пополнится автоматически

## 🐛 Решение проблем

### Если не видите изображения:

- Убедитесь, что сервер запущен
- Проверьте директорию `media/`
- Очистите кэш браузера

### Если при регистрации выдаёт ошибку:

- Проверьте, что имя пользователя уникально
- Email должен быть действительным
- Пароли должны совпадать

### Если при покупке ошибка "Недостаточно средств":

- Пополните баланс перед покупкой
- Проверьте сумму товаров в корзине
